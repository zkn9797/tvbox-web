#名称地址启用操作

网络（可选）

默认直连即可（已内置：3 秒连接超时、多 IP 轮换重试、失败时返回旧缓存）。若源站在 Cloudflare 上且直连常超时：可填写上游代理（如路由器上的 OpenClash/mihomo 混合端口 http://172.18.0.1:7890，填 auto 自动探测网关 7890/7897，留空=不用代理；代理不可用时自动回退直连），或填写 Cloudflare 优选IP（逗号/换行分隔，仅用于解析到 Cloudflare 的域名，SNI/Host 不变）。

Jar 爬虫运行时（spider-runtime）

肥猫/饭太硬等配置里的 csp_ 站点需要它。已内置在同一个容器里，留空即使用内置运行时；也可以填局域网里更强的电脑/x86 盒子上的地址。

网盘账号（夸克 / UC / 115 / 百度 / 阿里 等 Cookie）：部分 jar（如南风）自带配置页，需先在前台打开一次该配置里的任意站点让 jar 加载，然后 打开 jar 网盘配置页。

无头浏览器嗅探（sniffer）

普通嗅探找不到视频地址时，交给无头 Chromium 打开页面抓取（解析页、需要 WebView 的站点）。已内置在同一个容器里（lite 镜像不含），留空即使用内置嗅探器；也可以填局域网里更强机器上的地址。空闲 2 分钟自动关闭浏览器释放内存。
